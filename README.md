# Projeto-Portfolio-HTML-

# "ENG" 
This project showcases a portfolio website that I built using HTML, based on "The Complete Full-Stack Web Development Bootcamp" course on Udemy, taught by Angela Yu.

Este projeto HTML contém 3 arquivos (goal.png que mostra a foto da resolução do código, index.html que é onde eu desenvolvi o código por inteiro fazendo pequenas alterações na sua estrtura e também me baseando no código base e a resolution.html que mostra a resposta final do código).

Fiz esse projeto pelo Visual Studio Code (VS Code) e com a extensão do Live Preview, que mostra o codigo da resolução em simultaneo.
